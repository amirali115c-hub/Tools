How to Use the PDF Tools

Follow these simple steps to use the free online pdf tools tool:

  1. Pick a tool - Choose Compress, Extract Pages, Rotate, Merge, Page Numbers, or Info.
  2. Drop your PDF - Upload one or more PDF files depending on the tool you selected.
  3. Configure the settings - Set compression level, page ranges, rotation angle, or merge order.
  4. Process and download - Run the operation and download your processed PDF instantly.

Frequently Asked Questions

What PDF operations are available?

You can compress, extract pages, rotate, merge multiple PDFs, add page numbers, and view document info.

Is my PDF uploaded to a server?

No. All PDF processing runs locally in your browser using client-side libraries. Your documents stay on your device.

Can I merge multiple PDFs?

Yes, the Merge tool combines multiple PDFs into one file in the order you arrange them.

Can I extract specific pages?

Yes, the Extract tool lets you pull out individual pages or a range of pages into a new PDF.

Will compression reduce PDF quality?

You choose the compression level. Moderate compression reduces file size while preserving readable text and images.

Can I rotate PDF pages?

Yes, rotate any page by 90, 180, or 270 degrees, either for single pages or the whole document.
