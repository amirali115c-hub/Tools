How to Split PDF Files Online

Splitting PDF files has never been easier. Our free online PDF splitter allows you to separate pages from any PDF document in just a few simple steps:

  1. Drop your PDF - Drag and drop a PDF file into the upload area, or click to browse.
  2. Select pages - Click pages to select them, or enter page ranges (e.g., 1-3, 5, 7-10).
  3. Choose split mode - Select Extract (one file with selected pages) or Split (separate files by range).
  4. Configure options - Use Every N Pages mode for automatic splitting, or define custom ranges.
  5. Split and download - Click "Split PDF" and download your split files instantly.

Features of Our Free PDF Splitter

  • Page Preview - Visual thumbnails of all pages before splitting
  • Range Selection - Enter custom ranges like 1-3, 5, 7-10
  • Every N Pages - Automatically split every N pages
  • Visual Page Picker - Click pages to select/deselect
  • Extract Mode - Create single PDF with selected pages
  • Split Mode - Create separate PDFs by range

Frequently Asked Questions

How do I split a PDF for free?

Use our free PDF Splitter tool. Drag and drop your PDF, select pages or enter ranges (e.g., 1-3, 5, 7-10), choose split mode, and click Split. The split PDF files will download instantly. No uploads, no sign-ups required.

Is my PDF data uploaded to any server?

No, your PDF files never leave your device. All processing happens locally in your browser using client-side JavaScript. Your privacy is 100% guaranteed.

Can I split PDF by page ranges?

Yes, our PDF Splitter supports custom ranges. Enter ranges like 1-3, 5, 7-10 to split specific pages. You can also use the visual page picker to select pages.

Can I split every N pages?

Yes, our splitter has an "Every N Pages" mode. Set the number of pages per group and the PDF will be split into multiple files accordingly.

Can I preview pages before splitting?

Yes, our PDF Splitter renders thumbnail previews of all pages so you can visually select which pages to include in each split file.

What is the difference between Split and Extract?

Split creates multiple separate PDF files from your original. Extract creates a single new PDF containing only the selected pages.

How many PDFs can I create at once?

There is no limit. You can define as many split groups as needed and create multiple PDF files in a single operation.

Does this work on mobile devices?

Yes, our PDF Splitter works on all modern browsers including mobile. The interface is responsive and adapts to smaller screens.
