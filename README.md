# Free Tools Hub

A collection of free, private, client-side tools. Everything runs in your browser. No uploads, no accounts, no tracking. Your files never leave your device.

## Hosting

Free on GitHub Pages. No backend required.

## Tools

- Watermark Remover (video + image)
- Video Compressor
- Video to GIF
- Image tools (converter, resizer)
- PDF tools (to Word basic, compress)

## Run locally

Serve the folder with any static server, e.g.:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
